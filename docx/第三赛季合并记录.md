# 第三赛季合并记录

## 来源

- Alirea 基线为 `e23e43d`，含用户已有的策略和 Boss 配置。合并工作在 `codex/arkchess-act3-merge`。
- 官方数据取自服务端仓库的 `840876294bdcb0318d9251475afcde605ca45fac:packages/data/seasons/act3autochess.json`，SHA-256 为 `6d5cb56d1ae932a83feb5c8edcdc6d1d36f71795f1300994e62c021936fa9f6b`。

## 已应用的选择

- 折桠的官方 1 阶版本使用 `chess_ursus_1_91_a/b` 和独立特质。旧 2 阶版保留 `chess_char_2_17_a/b`，商店记录标记隐藏。隐现沿用自己的棋子配置。
- 调香师保留受伤回血，效果 ID 改为 `arkchess_aceffect_band_perfumer`。骑士团长使用官方主动技能及卡西米尔盟约效果替换记录。
- 「入门协议」采用官方独立训练表，奖励改用官方周期奖励和赛季商店。进度配置使用官方活动代币。

## 官方莱塔尼亚效果备忘

合并版采用 Alirea 的「女皇之声」和盟约 ID `leithanienShip`。已决定把官方莱塔尼亚的召唤效果留给后续策略。

- 原盟约为 `lethaniaShip`。官方源的 `effectInfoDataDict`、`effectDescParamDataDict` 和 `effectBuffInfoDataDict` 中均用 `bondeffect_lethania` 查找完整记录。
- 官方玩家 Buff 为 `act3autochess_bond_eff_lethania`，敌方入口为 `act3autochess_bond_eff_lethania[enemy]`。主机制提高本盟约干员和召唤物的攻击力，敌方单位被击倒时召唤「一个小节」。
- 玩家黑板的初始攻击倍率为 0.30，每层加 0.01。强化门槛为 6 人，召唤数量上限为 10／20，召唤概率为 100%。强化召唤物的基础概率为 0.30，每层加 0.001，上限为 1。精确数值和敌方带前缀的键以官方源为准。
- 编辑器参考表 `packages/season-editor/reference/buff_template_data.json` 中可查主模板、`_power`、`[summoner]`、`[summoned]`、`[enemy]` 和 `[enemy][stripbb]`。模板仍有以 `lethaniaShip` 为条件的节点。制作策略时要检查触发方式、目标、层数来源和召唤资源，再决定如何接入 Alirea 的成员。

## 棋子与盟约

- 同一干员优先采用官方阶位、技能、模组和特质。被换下的 Alirea 商店记录标记隐藏，原普通／精锐棋子和特质按原 ID 保留。官方棋子、特质的冲突 ID 重新分配，并同步普通／精锐查找及盟约成员引用。
- 新官方棋子承接对应 Alirea 棋子在自定义盟约中的成员资格，维持彩虹小队、卡兹戴尔、莱塔尼亚等自定义盟约的可用阵容。共有盟约的效果采用官方版，乌萨斯仍用 Alirea 暴击，莱塔尼亚继续用「女皇之声」。
- 卡兹戴尔采用官方乌萨斯的攻血、临时层数及六人高级效果。官方乌萨斯的四个模板复制为独立的卡兹戴尔模板，成员、层数引用和 Buff 键随目标盟约重绑。旧凋亡的配置在 [原卡兹戴尔盟约效果](原卡兹戴尔盟约效果.json)，原模板仍可查阅。

## 策略、装备与敌人

- 策略、装备、特殊敌人和盟誓的共用条目使用官方配置。已下放且与官方同名的策略收敛到官方入口，调香师与骑士团长保留各自玩法。
- 官方装备使用官方 ID。仅在 Alirea 存在的装备继续保留，冲突的旧装备 ID 迁移到独立键，并重绑升阶、融合及特质等引用。

## 全赛季设置

- 备战干员上限 10、备战装备上限 5、借用上限 30，采用官方值。
- 沿用核心／次要盟约分类和 8／2 抽取数量。伊比利亚列入核心类，聚合列入次要类。
- DIY 槽位没有干员 ID。Alirea 原有槽位保留原来的可见性，官方槽位用各自的记录装载。

## 模式、关卡与 Boss

- 官方 26 个模式均纳入，保留 Alirea 的 3 个独有单人模式。共用模式按官方配置导入，并加入原 Alirea 同模式可用且未被官方规则禁用的盟约。
- Boss 血量与回合关卡按模式保留各自来源。官方 `boss_11` 使用原生造型。Alirea 的迷迭香使用 `boss_alirea_rosmontis` 和专属音乐，只有保留的 Alirea 单人模式引用该 ID。
- 安装时，V079 共用客户端按当前模式查找原生关卡模板。未找到时，可用其他模式在同一关卡绑定的唯一原生 Boss 模板。合并版使用新版共用客户端分支 `codex/v079-boss-template-lookup` 的 `1ce61e7` 或含该提交的版本。
