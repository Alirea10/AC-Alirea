# Buff Template 事件列表

根据 `buff_template_data.json` 文件分析，以下是所有可用的触发事件类型：

## 事件分类

### 1. Buff 生命周期事件
| 事件名称 | 描述 | 使用次数 |
|----------|------|----------|
| **ON_BUFF_START** | Buff 开始时触发 | 非常频繁 |
| **ON_BUFF_FINISH** | Buff 结束时触发 | 频繁 |
| **ON_BUFF_TRIGGER** | Buff 定期触发（基于 triggerInterval） | 非常频繁 |
| **ON_BUFF_ENABLE** | Buff 启用时触发 | 中等 |
| **ON_BUFF_DISABLE** | Buff 禁用时触发 | 中等 |
| **ON_BUFF_LATE_ENABLE** | Buff 延迟启用时触发 | 少量 |

### 2. 伤害相关事件
| 事件名称 | 描述 | 使用次数 |
|----------|------|----------|
| **ON_TAKE_DAMAGE** | 受到伤害时触发 | 非常频繁 |
| **ON_CALCULATE_DAMAGE** | 计算伤害时触发 | 频繁 |
| **ON_OUTPUT_DAMAGE** | 输出伤害时触发 | 中等 |
| **ON_AFTER_OUTPUT_DAMAGE** | 输出伤害后触发 | 少量 |
| **ON_EVADE_DAMAGE** | 闪避伤害时触发 | 极少 |
| **ON_AFTER_CALCULATE_DAMAGE** | 计算伤害后触发 | 极少 |
| **ON_TAKE_EP_DAMAGE** | 受到 EP 伤害时触发 | 极少 |

| **ON_APPLYING_SKIPPED_MODIFIER** | 应用被跳过的修改器时触发 | 少量 |

## 详细说明

### ON_ES_OVER_ZERO
- **触发时机**: 当单位的 ES（元素强度，Element Strength）从 0 变为大于 0 时
- **典型用途**:
  - 基于 ES 值创建护盾或伤害
  - ES 达到阈值时触发特殊效果
  - 动态计算基于 ES 的属性

#### 用例 1: ES 触发范围伤害（Rogue 模式）
```json
{
  "templateKey": "rogue_1_damage_via_es",
  "eventToActions": {
    "ON_ES_OVER_ZERO": [
      {
        "$type": "Torappu.Battle.Action.Nodes+CreateBuffInRange",
        "_sourceType": "BUFF_OWNER",
        "_targetType": "BUFF_OWNER",
        "_targetOptions": {
          "targetSide": "ENEMY",
          "targetMotion": "ALL"
        },
        "_buffs": [
          {
            "buffKey": "damage_via_es",
            "templateKey": "rogue_1_damage_via_es[magic]",
            "lifeTimeType": "IMMEDIATELY"
          }
        ]
      },
      {
        "$type": "Torappu.Battle.Action.Nodes+CreateBuff",
        "_buff": {
          "buffKey": "damage_via_es[self]",
          "templateKey": "rogue_1_damage_via_es[self]"
        },
        "_buffOwner": "BUFF_OWNER"
      }
    ]
  }
}
```
**说明**: 当 ES 超过 0 时，对范围内的敌人创建伤害 Buff，同时给自己创建一个 Buff。

#### 用例 2: ES 护盾系统（Humus 技能）
```json
{
  "templateKey": "humus_t_1[shield]",
  "eventToActions": {
    "ON_BUFF_START": [
      {
        "$type": "Torappu.Battle.Action.Nodes+SetCharacterMaxEs",
        "_targetType": "BUFF_OWNER",
        "_maxEsRatio": 1
      },
      {
        "$type": "Torappu.Battle.Action.Nodes+AssignAttributeToBB",
        "_targetType": "BUFF_OWNER",
        "_attributeType": "MAX_HP",
        "_scaleVar": "max_hp_ratio",
        "_blackboardKey": "max_shield"
      }
    ],
    "ON_ES_OVER_ZERO": [
      {
        "$type": "Torappu.Battle.Action.Nodes+AssignAttributeToBB",
        "_targetType": "BUFF_OWNER",
        "_attributeType": "MAX_HP",
        "_scaleVar": "max_hp_ratio",
        "_blackboardKey": "max_shield"
      },
      {
        "$type": "Torappu.Battle.Action.Nodes+AssignEntityEsIntoBlackboard",
        "_blackboardKey": "es_value",
        "_targetType": "BUFF_OWNER"
      },
      {
        "$type": "Torappu.Battle.Action.Nodes+CalculateBlackboardValueViaParams",
        "_inputKey": "dynamic",
        "_outputKey": "dynamic",
        "_addParamKey": "es_value",
        "_maxValueKey": "max_shield",
        "_finalAbs": true
      },
      {
        "$type": "Torappu.Battle.Action.Nodes+CreateBuff",
        "_buff": {
          "buffKey": "humus_t_1[damage_via_es]",
          "templateKey": "humus_t_1[damage_via_es]"
        },
        "_buffOwner": "BUFF_OWNER"
      }
    ],
    "ON_TAKE_DAMAGE": [
      {
        "$type": "Torappu.Battle.Action.Nodes+BlockDamage",
        "_useDynamicVar": true,
        "_showShieldUI": true
      }
    ]
  }
}
```
**说明**: 
- Buff 开始时设置最大 ES 和护盾值
- 当 ES 超过 0 时，计算护盾值并创建护盾 Buff
- 受到伤害时，使用动态变量（护盾值）吸收伤害

### ON_BEFORE_EP_BREAK_START
- **触发时机**: 在 EP（元素点，Element Point）破断（Break）开始前触发
- **典型用途**:
  - 过滤 EP 破断恢复类型
  - EP 破断时发射投射物
  - 触发 EP 破断相关的伤害或效果

#### 用例 1: EP 破断时发射投射物（敌人技能）
```json
{
  "templateKey": "enemy_dirctr_t[aura2]",
  "eventToActions": {
    "ON_BEFORE_EP_BREAK_START": [
      {
        "$type": "Torappu.Battle.Action.Nodes+FilterEPBreakRecoveryType",
        "_target": "BUFF_OWNER",
        "_recoveryType": "SANITY",
        "_skipInEPBreakRecoveryCheck": true
      },
      {
        "$type": "Torappu.Battle.Action.Nodes+EmitProjectile",
        "_mountPoint": "MUZZLE",
        "_projectileKey": "projectile_enemy_dirctr_tr_1[p2]",
        "_useTileAsTarget": true,
        "_useTargetRootTile": true,
        "_actions": [
          {
            "$type": "Torappu.Battle.Action.Nodes+AdvancedApplyDamage",
            "_sourceType": "SOURCE",
            "_targetType": "TARGET",
            "_damageType": "MAGICAL",
            "_atkScaleVar": "atk_scale_aura",
            "_attackType": "NORMAL"
          },
          {
            "$type": "Torappu.Battle.Action.Nodes+ApplyElementDamage",
            "_elementDamageType": "SANITY",
            "_sourceType": "SOURCE",
            "_baseOnEnemyHostAtk": true,
            "_epDamageScale": "ep_damage_ratio"
          }
        ]
      }
    ]
  }
}
```
**说明**: 
- 首先过滤 EP 破断恢复类型为 SANITY（理智）
- 然后发射投射物到目标位置
- 投射物命中时造成魔法伤害和理智元素伤害

#### 用例 2: EP 破断时的光环效果
```json
{
  "templateKey": "enemy_dirctr_t[aura3]",
  "eventToActions": {
    "ON_BEFORE_EP_BREAK_START": [
      {
        "$type": "Torappu.Battle.Action.Nodes+FilterEPBreakRecoveryType",
        "_target": "BUFF_OWNER",
        "_recoveryType": "SANITY",
        "_skipInEPBreakRecoveryCheck": true
      },
      {
        "$type": "Torappu.Battle.Action.Nodes+EmitProjectile",
        "_projectileKey": "projectile_enemy_dirctr_tr_1[p2]",
        "_useTileAsTarget": true,
        "_actions": [
          {
            "$type": "Torappu.Battle.Action.Nodes+AdvancedApplyDamage",
            "_damageType": "MAGICAL",
            "_atkScaleVar": "atk_scale_aura"
          },
          {
            "$type": "Torappu.Battle.Action.Nodes+ApplyElementDamage",
            "_elementDamageType": "SANITY",
            "_epDamageScale": "ep_damage_ratio"
          }
        ]
      }
    ]
  }
}
```
**说明**: 类似用例 1，但是是光环效果版本，用于敌人 dirctr 的 aura3 技能。

### ON_BUFF_START
- **触发时机**: Buff 首次被添加到目标时
- **典型用途**: 
  - 初始化 Buff 状态
  - 创建衍生 Buff
  - 触发技能
  - 切换模式
  - 修改属性

### ON_BUFF_FINISH
- **触发时机**: Buff 生命周期结束时（时间到期、被移除等）
- **典型用途**:
  - 清理 Buff 效果
  - 恢复默认模式
  - 触发终结效果
  - 发射投射物

### ON_BUFF_TRIGGER
- **触发时机**: Buff 的定期触发器（由 `triggerInterval` 控制）
- **典型用途**:
  - 周期性伤害
  - 周期性治疗
  - 周期性检查条件
  - SP（技能点）回复

### ON_TAKE_DAMAGE
- **触发时机**: Buff 所有者受到伤害时
- **典型用途**:
  - 护盾吸收伤害
  - 伤害减免
  - 伤害反弹
  - 触发特殊效果

### ON_CALCULATE_DAMAGE
- **触发时机**: 计算伤害时（攻击前）
- **典型用途**:
  - 攻击力缩放（AtkScaleUp）
  - 伤害类型过滤
  - 条件判断（如阴阳系统）

### ON_OUTPUT_DAMAGE
- **触发时机**: 造成伤害时
- **典型用途**:
  - 伤害后附加效果
  - 生命偷取
  - 触发被动

### ON_AFTER_OUTPUT_DAMAGE
- **触发时机**: 造成伤害后
- **典型用途**:
  - 伤害后延迟效果
  - 记录伤害统计

### ON_EVADE_DAMAGE
- **触发时机**: 闪避伤害时
- **典型用途**:
  - 闪避后反击
  - 闪避后增益

### ON_OUTPUT_MODIFIER
- **触发时机**: 输出修改器时
- **典型用途**:
  - 修改器增强
  - 附加额外效果

### ON_APPLIED_MODIFIER
- **触发时机**: 修改器被应用后
- **典型用途**:
  - 记录修改器应用

### ON_APPLYING_MODIFIER
- **触发时机**: 正在应用修改器时
- **典型用途**:
  - 修改修改器属性

### ON_ABILITY_SPELL_ON
- **触发时机**: 施放技能时
- **典型用途**:
  - 技能施放后触发效果
  - 技能冷却修改

### ON_ABILITY_CAST_ON_TARGET
- **触发时机**: 技能对目标施放时
- **典型用途**:
  - 技能命中目标后效果

### ON_ABILITY_FINISH
- **触发时机**: 技能完成时
- **典型用途**:
  - 技能结束后清理

### ON_TARGET_KILLED
- **触发时机**: 击杀目标时
- **典型用途**:
  - 击杀奖励
  - 击杀触发效果

### ON_OWNER_KILLED
- **触发时机**: Buff 所有者被击杀时
- **典型用途**:
  - 死亡触发效果
  - 复活机制

### ON_OWNER_BORN
- **触发时机**: Buff 所有者出生时
- **典型用途**:
  - 出生时初始化

### ON_OWNER_POST_BORN
- **触发时机**: Buff 所有者出生后
- **典型用途**:
  - 出生后延迟初始化

### ON_OWNER_FINISH
- **触发时机**: Buff 所有者结束时（如撤退）
- **典型用途**:
  - 单位结束时清理

### ON_OWNER_LOCATE
- **触发时机**: Buff 所有者定位时
- **典型用途**:
  - 位置相关效果

### ON_BEFORE_ATTACK
- **触发时机**: 攻击前
- **典型用途**:
  - 攻击前准备
  - 攻击条件检查

### ON_OUTPUT_ATK_OR_HEAL
- **触发时机**: 输出攻击或治疗时
- **典型用途**:
  - 攻击/治疗增强

## 使用示例

### 示例 1: 周期性伤害 Buff
```json
{
  "templateKey": "periodic_damage",
  "eventToActions": {
    "ON_BUFF_TRIGGER": [
      {
        "$type": "Torappu.Battle.Action.Nodes+NoSourceDamage",
        "_damageType": "PURE",
        "_damageKey": "damage"
      }
    ]
  }
}
```

### 示例 2: 护盾 Buff
```json
{
  "templateKey": "shield",
  "eventToActions": {
    "ON_TAKE_DAMAGE": [
      {
        "$type": "Torappu.Battle.Action.Nodes+BlockDamage",
        "_filterDamageType": true,
        "_damageMask": "PHYSICAL_AND_MAGICAL"
      }
    ]
  }
}
```

### 示例 3: 模式切换 Buff
```json
{
  "templateKey": "mode_switch",
  "eventToActions": {
    "ON_BUFF_START": [
      {
        "$type": "Torappu.Battle.Action.Nodes+SwitchMode",
        "_modeIndex": 1,
        "_restartFSM": true
      }
    ],
    "ON_BUFF_FINISH": [
      {
        "$type": "Torappu.Battle.Action.Nodes+SwitchMode",
        "_modeIndex": 0,
        "_restoreDefault": true
      }
    ]
  }
}
```
