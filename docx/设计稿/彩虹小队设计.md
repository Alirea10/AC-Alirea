## 参数与效果链

| 参数 | 当前值 | 说明 |
|---|---:|---|
| base_atk / atk_per_stack | 400 / 3 | 攻击力平值及每层增量 |
| base_def / def_per_stack | 0.1 / 0.003 | 防御力比例及每层增量 |
| base_damage_scale / damage_scale_per_stack | 0.4 / 0.005 | 脆弱比例及每层增量 |
| weak[limit] | 2 | 脆弱持续时间，单位秒 |

主要模板为 buffTemplates/act1autochess_bond_eff_rainbow.json。角色的主盟约棋子 ID、精锐关系和特质绑定分别见 charChessDataDict/ 与 charShopChessDatas/。
