## 参数与效果链

| 配置 | 当前值 | 说明 |
|---|---|---|
| effectId | bondeffect_sami | 盟约效果注册记录 |
| Blackboard key | act1autochess_rule_register | 注册赛季战斗规则 |
| rule_kind / rule_group | opening_roll / sami_opening | 开局随机层数规则 |
| min_members | 2 | 规则生效的不同干员门槛 |
| roll_min / roll_max | -30 / 15 | 每次随机变化的下限和基础上限 |
| min_per_member / max_per_member | 0 / 5 | 每名萨米干员对范围边界的附加量 |
| target_bonds | self | 目标为每名干员自身所属的盟约 |

当前实现通过 effectBuffInfoDataDict 中的 rule_register 配置注册开局规则，不使用独立的 act1autochess_bond_eff_sami 模板文件。当前盟约的描述参数列表为空。
